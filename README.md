# LocalLibrary – Django Backend Project

LocalLibrary is a backend web application developed with Django for managing a local library.

The project focuses on the core backend structure of a library management system, including books, authors, genres, languages, and physical book copies.

## 🚀 Project Overview

The main objective of this project is to build a structured backend application using Django and its ORM to manage library data and relationships.

The application currently includes:

- Book management
- Author management
- Genre management
- Language management
- Book copy management
- Database relationships
- Django migrations
- Django administration interface

## 🛠️ Technologies

- **Python**
- **Django**
- **SQLite**
- **Django ORM**
- **Git / GitHub**
